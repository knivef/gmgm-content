# GMGM News Short-Form Blog Skill: Stablecoins

Write focused, search-led stablecoin articles for a broad but crypto-curious
audience. Each article should target one validated long-tail keyword and answer
one clear question better than the current SERP.

## Inputs Required

- Primary keyword
- Search intent
- Target reader
- Source links or research notes
- Desired publish date, if part of a calendar

If the keyword has not been validated, run the GMGM keyword research process first.

## Output Standard

- Length: 600-1,200 words
- Structure: headline, dek, intro, 3-5 H2s, concise conclusion
- Tone: plain-English, current, media-style, no hype
- SEO: use the primary keyword in title, intro, one H2, and meta description
- Include internal-link targets to related stablecoin and payments pieces

## Editorial Requirements

- Explain technical terms before using them heavily.
- Separate facts, market interpretation, and regulatory uncertainty.
- Do not offer financial advice.
- Include dates when covering laws, launches, depegs, or policy changes.
- Prefer recent primary sources, issuer pages, regulators, filings, and credible
  media reports.

## Deliverable Format

```markdown
# [SEO headline]

Meta title:
Meta description:
Primary keyword:
Secondary keywords:
Suggested slug:
Internal links to add:

[Article body]
```
